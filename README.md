# CampusLive - Smart Hostel System

## Overview
CampusLive is a modular automation portal built with Python and Flask. It provides a centralized digital solution for student accommodation matching, room utility repair ticket logging, and active campus exit tracking.

## Features
- Module 1: Automated room assignment based on preferences and dynamic capacities.
- Module 2: Full CRUD capabilities for recording and handling maintenance requests.
- Module 3: Digital out-pass verification and security checkpoint logging.

## Technologies Used
- Python 3
- Flask Framework

## Steps to Install & Run
1. Open your terminal in the project directory.
2. Install the necessary packages by typing:
   pip install -r requirements.txt
3. Start the application by running:
   python app.py
4. Access the server in your browser or tool at:
   http://127.0.0

## Instructions for Testing
To execute the automated evaluation test framework, run the following command in your terminal:
python -m unittest tests/test_api.py
